# Escape

Project type: Personal Project<br>
Platform: Web<br>
Genre: Action<br>
Subgenre: Maze<br>
Technologies: Unity 6, Git, Git LFS, GitHub

A casual maze game built with Unity 6.

How to play:
1. The game starts automatically when you open it on the browser.
2. You can move the camera to look around by moving your mouse.
3. You can move the player with WSAD or arrow keys.
4. You can jump by pressing Space Bar.
5. You can sprint by pressing Shift Key.
6. You can exit fullscreen mode by pressing Esc Key, you can press Esc Key to find your cursor icon because the cursor icon will disappear when you play the game.
7. The goal is to find the exit to go out from the maze.

Note:
1. Do not need to download or install this game in local to play it.
2. Open the game in fullscreen mode by clicking the blue button at the bottom right of the screen to get the better experience.
3. Click the link below to play this game directly.<br>
