# Escape

Project type: Personal Project<br>
Platform: Web<br>
Genre: Action<br>
Subgenre: Maze<br>
Technologies: Unity 6, Git, Git LFS, GitHub

A casual maze game built with Unity 6.

How to play:
1. The game starts automatically when you open it on the browser.
2. There are 2 obstacles that can kill you: (1) Tree on the ground, (2) Ghost in the sky
3. Press the Space Bar to fly over the obstacles temporarily.
4. The score at the top left of the game screen increases automatically as long as you can stay alive.
5. The score at the top right of the game screen is the highscore. The highscore can be replaced with the new score if your score is higher than it.
6. If you die, the button Game Over will appear. You can click it to start a new game.

Note:
1. Do not need to download or install this game in local to play it.
2. Open the game in fullscreen mode by clicking the blue button at the bottom right of the screen to get the better experience.
3. Click the link below to play this game directly.<br>
